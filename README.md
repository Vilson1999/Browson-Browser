## About

Browson is a native Android web browser developed by **Vilson Sonkar**. It combines everyday browsing tools with a Material 3 interface and options to personalize the home screen and browser appearance.

## Features

### Browsing
- Browse websites with back and forward navigation.
- Search the web using the configured search engine.
- Manage multiple tabs, including incognito tabs.

### Home screen and speed dials
- Open frequently visited sites from customizable speed dials.
- Add, edit, and remove speed-dial shortcuts.
- View recent history and selected bookmarks from the home screen.
- Customize the home screen with wallpaper options.

### Bookmarks
- Save, edit, organize, and remove bookmarks.
- Group bookmarks into folders.
- Import bookmarks and export them as JSON or HTML.
- Add bookmarks to the home screen or speed dials.

### Downloads and history
- View downloads and pause, resume, or delete download items.
- Pause or resume all downloads and clear completed items.
- Review browsing history, revisit pages, delete entries, or save pages as bookmarks.

### Appearance and settings
- Choose system, light, dark, or AMOLED theme modes.
- Customize interface gradients and app colors.
- Select home wallpaper modes and styles.
- Adjust animations and configure the default search engine.
- Customize the browser menu and toolbar tools.

## Build

Build the Android app with the included Gradle wrapper:

```bash
./gradlew assembleDebug
```

The debug APK is generated under `app/build/outputs/apk/debug/`.
